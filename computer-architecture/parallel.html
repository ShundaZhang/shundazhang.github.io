Coherence tracks ownership of one line

A protocol such as MESI tracks states such as Modified, Exclusive, Shared and Invalid. Snooping and directories are ways to coordinate which agents have copies. Exact states and interconnects depend on the implementation. SIMD works across lanes within an instruction, SMT shares core resources between hardware threads, and multiple cores execute instruction streams with separate or shared caches.

Ordering connects observations at different addresses

Coherence concerns one location. A memory consistency model constrains how reads and writes to different locations may be observed. In this hardware litmus test, x and y are initially zero and occupy distinct normal memory locations.

Core 0             Core 1
x = 1              y = 1
r0 = y             r1 = x

Can (r0, r1) = (0, 0)?

Yes under the usual x86 ordering rules for normal write-back memory, and under RVWMO without additional ordering. On x86 a store can wait in the local store buffer while a later load reads another address. An appropriate full store-to-load barrier on both cores rules out this outcome. RISC-V also provides FENCE and acquire/release semantics for supported atomic instructions, with RVWMO as the base model and Ztso as an optional extension.

For shared state in C or C++, use language atomics and synchronization. A release store and an acquire load that reads from it can publish prior data. Compiler ordering, ISA ordering and the rules for device memory each need their own treatment.

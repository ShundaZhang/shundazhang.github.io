08 / PRACTICE

Test the model

Try three small calculations in the browser, then compare the model with a real platform.

Map an address to a cache setSplit a Sv39 addressBudget branch stallsInspect an actual platform

Map an address to a cache set

The model uses a 32 KiB cache with 64-byte lines. The address is a toy physical address with simple indexing. Change the ways while keeping capacity fixed, and observe how the number of sets and the tag change.

Split a Sv39 address

Split a canonical 64-bit Sv39 virtual address into three 9-bit indices and a 12-bit offset. Enter 0x0000004000000000 to see a noncanonical address. A translation also needs page tables and permission checks.

Budget branch stalls

The model starts with base CPI 1 and adds branch frequency × misprediction rate × penalty. It assumes the added work does not overlap. Real out-of-order cores require measurement.

Inspect an actual platform

On Linux, compare lscpu, /proc/cpuinfo, /sys/devices/system/cpu/cpu0/cache/index*/ and /proc/interrupts. For each cache, inspect level, type, coherency_line_size and shared_cpu_list. Tool and field availability depends on the kernel and hardware. In QEMU, inspect the guest ISA and device model. Collect cache latency and PMU measurements on real hardware or a model that explicitly simulates timing.

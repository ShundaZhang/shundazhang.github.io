SYSTEMS / FIELD GUIDE

计算机体系结构

沿指令、地址与数据理解计算机如何工作，用 x86-64 和 RISC-V 对照指令集、核心与平台三个层次。

从指令开始 →打开实验

课程学习路线

先具备 C、指针、十六进制和基本布尔逻辑知识。按顺序读完 01–05 章，再学习多核、性能与 AI 体系结构。遇到观测结果，先用实验检查自己的解释，再查手册。

01 / ISA / ABI

指令集

用同一段 C 代码对照指令、寄存器、特权与调用约定。

→02 / DATAPATH / CORE

CPU 微架构

从数据通路开始，理解流水线、冒险、推测执行和提交。

→03 / LOCALITY / CACHE

缓存

跟算地址映射，再理解局部性、替换、写策略和未命中代价。

→04 / TRANSLATION / DRAM

内存

对照 x86-64 分页与 RISC-V Sv39，继续追踪 DRAM 和 NUMA 路径。

→05 / DEVICE / BUS

I/O

沿一条设备队列理解 MMIO、PCIe、中断、DMA 和 IOMMU。

→06 / COHERENCE / ORDERING

多核

理解缓存一致性、伪共享以及跨地址的内存顺序。

→07 / CPI / MEASUREMENT

性能

用 CPI、Amdahl、Roofline 和硬件计数器检验性能假设。

→08 / GPU / MEMORY SYSTEMS

AI 体系结构

沿推理的数据路径理解 CPU、GPU、HBM、CXL 和近存／存内计算。

→09 / PRACTICE

实验

拆解地址，试算缓存映射、CPI 和 KV 容量。

A route through the course

Start with C, pointers, hexadecimal and basic Boolean logic. Work through chapters 01–05 in order, then study multicore, performance and AI systems. Use the exercises to check whether you can explain an observation before opening a manual.

01 / ISA / ABI

ISA

Compare instructions, registers, privileges and calling conventions through one C example.

→02 / DATAPATH / CORE

CPU

Build a datapath and trace pipelining, hazards, speculation and retirement.

→03 / LOCALITY / CACHE

Cache

Work through address mapping, locality, replacement, write policies and miss cost.

→04 / TRANSLATION / DRAM

Memory

Walk x86-64 paging and RISC-V Sv39, then follow the request to DRAM and NUMA.

→05 / DEVICE / BUS

I/O

Follow MMIO, PCIe, interrupts, DMA and IOMMU through a device queue.

→06 / COHERENCE / ORDERING

Multicore

Separate cache coherence, false sharing and cross-address memory ordering.

→07 / CPI / MEASUREMENT

Performance

Use CPI, Amdahl, Roofline and hardware counters to test a performance hypothesis.

→08 / GPU / MEMORY SYSTEMS

AI Systems

Follow inference through CPUs, GPUs, HBM, CXL and processing near memory.

→09 / PRACTICE

Labs

Decode an address, exercise a cache, and estimate CPI and KV memory.

Courses and manuals

Berkeley CS61C pairs lecture notes and labs with RISC-V assembly and datapath design. MIT Computation Structures builds from logic and state to pipelines, caches and virtual memory. The ISA manuals define exact behavior, and Linux driver documentation explains how the OS uses platform interfaces.

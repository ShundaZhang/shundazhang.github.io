# Computer Architecture Atlas

An English and Chinese field guide to CPU cores, memory and device I/O, with x86-64 and RISC-V examples.

GitHub Pages serves this directory at [Computer Architecture](https://shundazhang.github.io/computer-architecture/). To update the generated pages, edit `chapters.py` or `build.py`, then run `python3 -B build.py` from this directory. The site and browser labs use local static assets. Start a static server from the parent directory to preview the home page and the language switch together.

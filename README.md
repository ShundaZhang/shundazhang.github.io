The résumé is a concise bilingual technical profile, with selected experience, projects, teaching and education. It excludes personal contact information and private source documents. ByteDance work is described only by broad technical areas, with a confidentiality note.

New independent directions can be added to the directory without changing the homepage structure. Learning directions and personal experience pages do not require a shared narrative.

The homepage uses static HTML/CSS and a language-selection script. Topic sites live at sibling project paths.

Rebuild the curated public résumé with `python3 -B resume/build.py`. No private files or credentials are required to build it.

# AI Agent Security Atlas

Bilingual field guide for cloud execution isolation, tool authorization, and data protection. Public product documentation was reviewed on 15 November 2026. The policy lab is a local, deterministic illustration and runs no model calls, tools, or network requests.

Rebuild from the homepage checkout with `python3 -B agent-security-atlas/build.py`. The generated pages are published by GitHub Pages and inherit the homepage language preference.
